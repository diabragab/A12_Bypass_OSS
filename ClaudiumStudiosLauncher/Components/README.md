# Claudium Studios Launcher Components

The premium launcher shell uses reusable resource-based components from `Themes/ClaudiumDark.xaml`:

- `PremiumButtonStyle` / `PlayButtonStyle` for cinematic primary actions.
- `GlassButtonStyle` and `DangerButtonStyle` for secondary and destructive actions.
- `SidebarButtonStyle` for the floating launcher navigation rail.
- `GlassCardStyle` for translucent panels, cards, action areas, and settings sections.

These resources keep the Claudium Studios visual language consistent across pages while preserving the existing MVVM and service architecture.
